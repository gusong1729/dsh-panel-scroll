# v0.2.4

> DeepSeek Harness 侧栏滚动补丁：左侧面板列表固定 N 行（默认 4）可滚动，右侧栏被裁掉的内容改为可滚。

这一版把「看起来滚不动」的四类问题都修完了，并且让「卸载不残留」变成能被测试断言的事实。

## 修了什么

**1. 面板列表吃掉半个侧栏**
`sidebar.panellist` 有几个面板就长几行，「工作区」被挤出窗口。现在默认只露 4 行（`学习/插件/插件市场/自动化任务`），其余的滚轮滑出来，工作区整体上移。

**2. 右栏顶部第一项永远看不见**
滚到最顶，最上面那个按钮还是不出现。根因不是「没滚动条」，而是某个 **居中对齐**（`justify-content: center`）的容器，内容比它高，多出来的部分漏到了**它自己的上边界之外** —— `scrollHeight` 不计入、任何 `scrollTop` 也够不到。而它本身是 `overflow: visible`，所以只看「被裁剪的溢出」根本发现不了。现在改为**先按几何位置判起始侧溢出**，命中就把对齐改回 `flex-start`，让它变成正常的下方溢出。

**3. 右栏底部内容被裁掉**
内容比盒子高、又被 `overflow: hidden/clip` 切掉的容器，现在改成可滚。

**4. 卸载后残留**
早期版本用内联样式，卸载插件后左栏会保持封顶直到刷新。现在所有效果都走**注入的样式表 + 类名**，`dispose()` 会摘掉样式表和加过的类 —— 冒烟测试里已经对这条做了断言。

## 顺手加固

- 用户**自己滚过的**容器不再被误判为起始侧溢出（这会把 `justify-content: flex-start` 强加到正在浏览的面板上）
- 扫描改成「先全量测量、再统一写入」，右栏开着大编辑器时不再逐元素触发布局
- 修复是级联的（改完子元素，父容器才出现溢出），现在同一轮内最多重算 6 次，不再等 5 秒轮询
- 每 40ms～5s 的轮询全部降级为兜底，主要靠 MutationObserver / resize 驱动

## 安装 / 升级

```bash
# 本地目录
dsh plugin --profile <你的 profile> add /绝对路径/dsh-panel-scroll

# npm（发布后）
dsh plugin --profile <你的 profile> add dsh-panel-scroll
```

装完重启一次 DSH；之后改代码只需刷新页面。

## 配置（localStorage，改完刷新即生效）

| 键 | 默认 | 说明 |
|---|---|---|
| `dsh-panel-scroll:rows` | `4` | 面板列表显示几行（1–20）。设成 `3` 时算上「学习」那行正好 4 行 |
| `dsh-panel-scroll:unclog` | 开 | 设 `"off"` 只保留左侧封顶，关闭右栏修复 |

## 已知限制

- 依赖 shell 的 DOM 层级（但**不依赖类名**：DSH 用的是 CSS Module 哈希类名，如 `wtg9ga_`、`acoR2W_`）。shell 改结构时表现为「没效果」，不会弄坏界面。
- 在 `dsh 0.2.1-rc.2` 上验证。
- 高度 < 60px 的被裁容器不处理。
- 右栏关闭时，「贴右边的那条」是主区，因此规则也会作用到主区（可用 `unclog: off` 关闭）。

## 验证

- `node tests/smoke.mjs` — apply / 槽位注册 / 右栏容器打补丁 / dispose 清理
- `tests/harness.html` — 复刻 shell 骨架，在真实浏览器里验收（居中与 `flex-end` 两种对齐都覆盖）

---

### English

Fixes four cases where the DSH sidebar looked unscrollable: the panel list now shows N rows (default 4) and scrolls, right-column content that was clipped becomes scrollable, and **start-edge overflow** from centred or end-aligned flex containers — the "scroll to the top and the first item is still missing" bug — is detected by geometry and re-aligned so it becomes reachable. Uninstalling now leaves nothing behind: every effect goes through one injected stylesheet plus classes. Verified on `dsh 0.2.1-rc.2`.
